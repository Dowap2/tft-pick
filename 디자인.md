Build a modern TFT (Teamfight Tactics) gaming analytics website.

The website is a data-focused TFT composition platform where users can browse,
filter, and inspect team compositions, champion combinations, recommended items,
level-by-level boards, and statistics.

The overall design should feel like a premium esports analytics platform,
not a generic gaming landing page.

==================================================
1. DESIGN DIRECTION
==================================================

Visual style:

- Premium competitive gaming analytics dashboard
- Dark mode by default
- Clean, dense, information-focused interface
- Modern esports aesthetic
- Professional and polished
- Prioritize readability and information hierarchy
- Inspired by modern gaming statistics websites, but do NOT copy any existing website

Avoid:

- Excessive neon effects
- Excessive gradients
- Excessive glassmorphism
- Large decorative illustrations
- Excessive animations
- Huge empty spaces
- Overly rounded UI
- Generic SaaS landing page design

The website should immediately feel like:

"Professional TFT competitive data platform"

rather than:

"Gaming-themed marketing website"

==================================================
2. COLOR SYSTEM
==================================================

Background:

- Main background: very dark navy / charcoal
- Example direction: #0B0D12

Surface:

- Cards and panels should use slightly lighter dark gray
- Example direction: #14171F

Borders:

- Very subtle gray borders
- Borders should separate sections without becoming visually dominant

Primary accent:

- Electric blue / indigo

Secondary accent:

- Purple

Semantic colors:

- Positive statistics: subtle green
- Negative statistics: subtle red
- Warning: subtle yellow

Do not use highly saturated neon colors across the entire UI.

Accent colors should mainly be used for:

- Active filters
- Selected tabs
- Important statistics
- Tier badges
- Interactive elements
- Hover states

==================================================
3. TYPOGRAPHY
==================================================

Use:

- Pretendard as the primary font
- Rajdhani only for selected English text and important statistics/numbers

Typography hierarchy:

- Large page title: bold
- Section titles: semibold
- Card titles: semibold
- Body text: regular
- Labels: medium
- Statistics: bold

Korean text must remain highly readable.

Statistics and numbers should have strong visual hierarchy.

Do not use Rajdhani for the entire website.

==================================================
4. GLOBAL LAYOUT
==================================================

Desktop-first responsive design.

Maximum content width:

- Approximately 1200~1400px

Structure:

Top Navigation
↓
Page Header
↓
Search / Filters
↓
Composition List
↓
Composition Cards

Desktop:

- Fixed or sticky top navigation
- Optional left filter sidebar
- Main content area
- Generous but controlled spacing

Mobile:

- Collapse navigation
- Filters become a drawer or expandable section
- Composition cards become single-column
- Preserve important statistics
- Avoid horizontal overflow

==================================================
5. TOP NAVIGATION
==================================================

Create a minimal dark navigation bar.

Left:

- Website logo / text logo
- Example: TFT Analytics

Navigation:

- 덱
- 챔피언
- 아이템
- 증강

Right:

- Search
- Patch indicator
- Optional settings/theme button

The navigation should be compact.

Do not make the header oversized.

==================================================

The composition card is the most important component.

Each card should contain:

Top section:

- Tier badge
- Composition name
- Short description
- Average placement

Champion section:

- Champion portraits
- Champion names
- Cost
- Star level where applicable

Carry section:

- Main carry
- Secondary carry
- Tank

Item section:

- Recommended items
- Item icons
- Item priority

Statistics:

- Win rate
- Pick rate
- Average placement
- Games played

==================================================

When a user selects a composition, open a detailed page.

Header:

- Tier
- Composition name
- Description
- Patch
- Statistics

Main sections:

1. Final Board

11. TIER SYSTEM
==================================================

Tier badges:

S
A
B

Use visually distinct but restrained colors.

The badge should be immediately recognizable.

Do not make tier colors overpower the rest of the card.

==================================================
12. DATA TABLE
==================================================

Create an optional detailed statistics table.

Columns:

- 덱
- 티어
- 평균 등수
- 승률
- 픽률
- 게임 수

Allow:

- Sorting
- Filtering
- Pagination

Mobile should transform into cards or horizontally scroll.

==================================================
13. INTERACTIONS
==================================================

Use subtle animations only.

Examples:

- Card hover
- Button hover
- Filter transitions
- Tab transitions
- Expand/collapse

Animation duration:

Approximately 150~200ms.

Avoid:

- Large page transitions
- Bouncing effects
- Excessive parallax
- Constant animated backgrounds

==================================================
14. UX PRINCIPLES
==================================================

The user should understand the key information of a composition within 2 seconds.

Prioritize:

1. Composition
2. Tier
3. Main carry
4. Items
5. Average placement
6. Win rate
7. Pick rate

Minimize unnecessary clicks.

Important information should be visible without opening a modal.

Use clear visual hierarchy.

==================================================
15. EMPTY / LOADING / ERROR STATES
==================================================

Implement:

- Skeleton loading
- Empty search results
- No data state
- API error state

Skeletons should match the actual card layout.

Do not use generic loading spinners everywhere.

==================================================
16. RESPONSIVE DESIGN
==================================================

Desktop:

- Multi-column composition grid
- Sidebar filters
- Dense statistics

Tablet:

- Reduced columns
- Collapsible filters

Mobile:

- Single-column cards
- Horizontal scrolling for level boards
- Bottom sheet or drawer for filters
- Compact navigation
- Maintain readable statistics

No horizontal overflow on the overall page.

==================================================
17. VISUAL DETAILS
==================================================

Use:

- 8~12px border radius
- Subtle borders
- Minimal shadows
- Strong spacing consistency
- Compact cards
- High contrast typography

Do not overuse rounded containers.

Do not make every element look like a floating card.

==================================================
18. SEO
==================================================

The website should be SEO-friendly.

Each page should have:

- Unique title
- Unique meta description
- Proper H1
- Semantic HTML
- Open Graph metadata
- Canonical URL
- Sitemap support
- robots.txt support

Example title:

"TFT 덱 티어 리스트 - 최신 패치 조합 분석"

Example description:

"최신 TFT 패치 기준 티어별 덱과 챔피언 조합,
추천 아이템, 레벨별 보드를 확인하세요."

Composition detail pages should generate unique metadata
based on the composition.

==================================================
19. ACCESSIBILITY
==================================================

Ensure:

- Good text contrast
- Keyboard navigation
- Visible focus states
- Meaningful button labels
- Alt text for important images
- Semantic HTML

Do not rely only on color to communicate information.

==================================================
20. OVERALL RESULT
==================================================

The final result should look like a real production-ready TFT
analytics website.

The design should feel:

- Competitive
- Premium
- Technical
- Data-driven
- Fast
- Clean
- Modern

The primary goal is not visual decoration.

The primary goal is helping TFT players quickly discover:

"What should I play?"

"How should I build it?"

"What items should I use?"

"How should my board look at each level?"

"How is this composition performing?"

Build the interface around those questions.

Font implementation:

Use Pretendard as the primary Korean UI font.

Use Rajdhani only for:
- English headings
- Large numerical statistics
- Patch numbers
- Small esports-style labels

Do not use Rajdhani for Korean body text.

The typography should prioritize Korean readability.
